What works now

  • One binary (13 MB with the UI) serves /api, /files and the embedded Nuxt app. Unknown paths get 200.html.
  • AutoMigrate creates all 23 tables on the local MariaDB 11.8. A second start changes nothing.
  • Sign up, verify mail (through the outbox to Mailpit), log in by email or username, one session per user, forgot and reset password, change password, log out.
  • A real Django pbkdf2_sha256 hash logs in and is replaced with argon2id.
  • A cookie request that changes data from another origin (for example a lab site) gets 403.
  • progress.Record is the one writer of users.xp. Event rows never change it.
  • Content import from the Postgres copy: 43 paths (27 published), 752 modules, 434 activities, 763 challenges (367 published), 4 plans, the 30 ranks and the onboarding survey. 2,832 content files copied.
  • The old flag hashes work: 30 flags found in the old lab sources match their stored HMAC hashes with the copied pepper.
  • Practice: challenge list with filters, detail, flag submit (machines with several flags), hints in order with XP cost.
  • Learn: paths, lessons, quiz grading, module completion with XP, path certificates with a public check.
  • Teams: create, invite, join request, join code, accept, remove, owner transfer, member limit.
  • Settings table with typed values, defaults in code, admin list and PATCH.
  • Zero-downtime upgrade with tableflip on SIGHUP (not yet tested under load).
  • The browser makes no request to a third-party host. Inter and Lucide icons are bundled.

Decisions to review

I made these choices without asking. Each one is easy to change.

  • Echo v5 (v5.4.4, stable) instead of v4.
  • Module path is csema.
  • OAuth without a library. The Google and GitHub code flow uses the standard library only. The provider URLs are in code, because the providers fix them.
  • User tiers are free, prime, elite. The old basic becomes free at migration.
  • Challenge difficulty keeps the old 4 values: easy, medium, hard, expert.
  • Extra columns not in the ERD: paths.tier (prime and elite paths), plans.features and plans.position (the pricing page reads them), lab_sessions.password (SSH gateway), subscribers.status = pending (double opt-in), mail_outbox.headers (one-click unsubscribe), users.disabled.
  • Technical constants stay in code: drain timeout (30 s), mail retry (5 attempts), argon2id cost, DB pool size. Business values are in settings: session days, token lifetimes, minimum password length, auth rate limit, body limit, ranks.
  • Ranks default to one rank in code. The content import will store the 30 current ranks in the settings table.
  • Machine flags keep the old questions: one flag part for each question, each with its own XP. The last part marks the machine solved with 0 XP, so XP is not counted twice.
  • Activity XP is 0. As before, only module completion gives XP. A quiz keeps its score.
  • Global teams: a user can be in more than one team (as before). Team XP is the sum of the members' XP.
  • tygo is pinned as a Go tool (go tool tygo generate).
