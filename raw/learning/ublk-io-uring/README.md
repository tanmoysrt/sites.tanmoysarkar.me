# ublk and io_uring deck

`slides.md` is the Marp source. The SVG diagrams in `assets/` are generated by `diagrams/gen.mjs` with rough.js. The `uring-N.svg` and `read-copy-N.svg` files share one diagram each and highlight one step at a time.

To change a diagram, edit `diagrams/gen.mjs`, then run from the repository root:

```sh
(cd raw/learning/ublk-io-uring/diagrams && npm install)
(cd raw/learning/ublk-io-uring/diagrams && node gen.mjs ../assets)
npm run build:deck -- learning ublk-io-uring < /dev/null
```

Close stdin when you run Marp from a script, or it waits for input.
