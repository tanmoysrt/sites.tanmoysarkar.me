# Frappe Cloud v2 architecture deck

`slides.md` is the Marp source. The SVG diagrams in `assets/` are generated by `diagrams/gen.mjs` with rough.js. The five `create-N.svg` files share one sequence diagram and highlight one step each.

To change a diagram, edit `diagrams/gen.mjs`, then run from the repository root:

```sh
(cd raw/learning/frappe-cloud-v2-architecture/diagrams && npm install)
node raw/learning/frappe-cloud-v2-architecture/diagrams/gen.mjs raw/learning/frappe-cloud-v2-architecture/assets
npm run build:deck -- learning frappe-cloud-v2-architecture
```
