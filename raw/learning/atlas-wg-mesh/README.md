# WG Mesh deck

`slides.md` is the Marp source. The SVG diagrams in `assets/` are generated by `diagrams/gen.mjs` with rough.js.

To change a diagram, edit `diagrams/gen.mjs`, then run from the repository root:

```sh
(cd raw/learning/atlas-wg-mesh/diagrams && npm install)
node raw/learning/atlas-wg-mesh/diagrams/gen.mjs raw/learning/atlas-wg-mesh/assets
npm run build:deck -- learning atlas-wg-mesh
```
