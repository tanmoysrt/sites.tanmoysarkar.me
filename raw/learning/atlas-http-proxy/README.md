# HTTP proxy deck

`slides.md` is the Marp source. The SVG diagrams in `assets/` are generated by `diagrams/gen.mjs` with rough.js.

A flow diagram loops a message icon along the arrows of its current step with SMIL, and its header strip shows the headers on each arrow. An orange cell is a header that the step added or changed. With reduced motion, the diagram shows the last header strip without movement.

To change a diagram, edit `diagrams/gen.mjs`, then run from the repository root:

```sh
(cd raw/learning/atlas-http-proxy/diagrams && npm install)
node raw/learning/atlas-http-proxy/diagrams/gen.mjs raw/learning/atlas-http-proxy/assets
npm run build:deck -- learning atlas-http-proxy
```
