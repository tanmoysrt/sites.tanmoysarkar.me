Pilot QA screen map

Pilot admin, develop plus fixes on branch fix/qa-round. Fresh VM: 2 vCPU, 7.8 GB RAM, Ubuntu, MariaDB, Frappe v16, ERPNext. Tested 12 November 2026.

Pilot is a CLI and admin dashboard that runs Frappe benches on one server. This page shows each admin screen that we opened during the test. Each screen is a card. An arrow shows the action that moves you from one screen to the next. Select a card to see the full screenshot and the notes.

We installed Pilot on an empty VM with the install script, ran the setup wizard, and created two sites. Then we used each screen as an operator would. Most of the work went to the features added after pre-release 100 and to the core paths: sites, app installs, backups, the DB analyzer, and the database settings. When a screen was wrong, we found the cause, fixed it on the branch, deployed the fix to the VM, and tested the screen again.
